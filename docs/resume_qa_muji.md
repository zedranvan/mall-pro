### 景区票务预约与订单履约系统（功能与接口测试）

`Postman` `MySQL` `Charles` `JMeter` `禅道`

覆盖景区门票微信小程序在线预约、退票退款、日历库存扣减以及线下扫码核销的全流程功能测试与接口验证。

- **核心流程测试用例设计**：针对小程序端“实名限购、日历库存选择、超时取消订单、线下扫码核销”等核心功能设计测试用例，覆盖正向流程与常见取消逆向场景。
- **接口功能与状态码校验**：使用 Postman 对订单创建、支付回调及核销接口进行参数测试，验证必填项、超长字符及异常参数的返回值与错误提示是否符合接口文档规范。
- **网络异常与弱网抓包排查**：使用 Charles 模拟网络延迟场景，测试核销接口在网络不稳定连续点击时的表现，协助研发增加防重校验，防止同一张票被重复核销。
- **后台数据库数据比对**：在数据库中编写 SQL 查询验证订单状态流转，比对用户下单、支付后门票库存与订单明细是否一致，确保无脏数据遗留。

### SaaS 短链接生成与访问统计系统（功能与接口验证）

`Postman` `Python` `MySQL` `Redis` `JMeter`

面向长链接转换短链接、点击跳转重定向及访问次数统计的功能测试与稳定性验证。

- **短链接生成与边界校验**：针对不同协议的长网址、包含特殊字符的链接进行边界输入测试，验证系统生成的 6 位短码是否唯一且跳转准确。
- **无效短链接前置拦截验证**：模拟输入大量不存在的短链接进行请求，验证系统是否能快速返回 404，确认无效请求不会对后端系统造成阻塞。
- **重定向跳转与数据核对**：使用 Postman 检查 302 临时重定向状态码与跳转地址；通过 SQL 查询比对前台短链点击次数与后台数据库记录是否一致。
- **基础并发访问验证**：使用 JMeter 进行简单的并发点击测试，观察高频访问下短链接跳转的响应速度与稳定性。
