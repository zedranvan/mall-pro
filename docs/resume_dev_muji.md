## 项目

### 景区票务预约与订单履约系统

`Java` `Spring Boot` `MySQL` `Redis` `Kafka`

面向景区门票在线预约、实名购票与线下扫码核销的后端业务系统，负责订单流转、库存扣减及出票通知。

- **库存防超卖处理**：在门票抢购场景中，将库存预先保存在 Redis 中进行扣减判断，并在数据库中使用非负约束与版本号校验，防止因并发点击导致门票超卖。
- **出票通知异步重试机制**：为避免网络抖动导致出票消息发送失败，在生成订单时将出票事件记录存入本地任务表，通过后台定时任务将未发送的记录重新推送到消息队列，保证出票通知能稳定送达。
- **订单状态流转控制**：设计清晰的订单状态变化流程（待支付、已出票、已核销、已退款），在更新状态时核对当前状态与版本号，防止网络超时重发导致同一张票被重复核销。
- **接口响应耗时优化**：在接口压测中发现响应偏慢，排查发现事务中包含了不必要的耗时校验；通过精简事务范围，将只读校验移至外部，缩短了数据库占用时间，提升了接口稳定性。

### SaaS 短链接生成与访问统计系统

`Java` `Spring Boot` `MySQL` `Redis` `Caffeine`

面向日常推广与短信分发的短链接转换系统，负责将长网址生成简短链接、提供跳转重定向及统计访问次数。

- **短链接生成与防重复**：使用哈希算法将长链接压缩为 6 位短码，并加入防冲突重试逻辑，确保每个短码全局唯一，生成的链接简短规整。
- **无效请求前置过滤**：引入布隆过滤器快速判断请求的短码是否存在，直接拦截大量不存在的错误短码请求，避免无效流量频繁查询数据库。
- **302 跳转与多级缓存**：选用 302 临时重定向实现链接跳转，保证每次访问都能经过后端服务进行统计；使用本地缓存与 Redis 缓存常用热点短链接，加快跳转响应速度。
- **访问量计数与异步记录**：针对短链接的点击访问，先在 Redis 中进行原子累加计数，再通过后台定时任务批量将统计数据同步到 MySQL 中，避免每次点击都频繁更新数据库。
